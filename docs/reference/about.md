# О проекте Orbit AI

**Orbit AI** — экосистема сервисов для студентов Московского Политеха: актуальное расписание занятий, навигация по сложным корпусам, трекер дедлайнов и AI-консультант по учебным вопросам.

Проект создаётся инженерной командой студентов факультета Информационных технологий (группа 261-334).

---

## 1. Миссия и решаемые проблемы

Первокурсники и студенты технических вузов ежедневно сталкиваются с организационным хаосом:
1. **Навигационный тупик:** Десятки корпусов, разбросанных по Москве (Большая Семёновская «БС», Автозаводская «АВ», Прянишникова «ПР», Михалковская «МИХ»), закрытые переходы и неочевидная нумерация аудиторий приводят к постоянным опозданиям на пары.
2. **Путаница в расписании:** Сбои серверов расписания в начале семестра, переносы пар, чередование числителя и знаменателя (четных и нечетных недель).
3. **Бюрократия и регламенты:** Сложности с получением справок об обучении для военкомата, непонимание балльно-рейтинговой системы (БРС) и правил перевода на бюджет.
4. **Потеря дедлайнов:** Лабораторные работы и расчетно-графические задания сдаются в последний момент из-за отсутствия единого трекера задач.

**Цель Orbit AI** — предоставить единый удобный цифровой шлюз (мобильное приложение, Telegram-бот и RAG-ассистент), который отвечает на любые вопросы по вузу за секунды и помогает успешно учиться без стресса.

---

## 2. Архитектурные принципы

Инженерная основа проекта построена по стандартам современной коммерческой разработки:
- **Clean Architecture & Domain-Driven Design:** Строгая изоляция предметной области от инфраструктуры.
- **Microservices Polyrepo:** 14 независимых репозиториев в организации [`orbit-polytech`](https://github.com/orbit-polytech).
- **Schema-First API:** Все контракты фиксируются в Protobuf v3 через `Buf CLI` в `contracts`.
- **Гибридный транспорт:** Высокоскоростной бинарный gRPC/HTTP/2 во внутреннем контуре и REST/OpenAPI на внешнем шлюзе.
- **Надежность доставки:** Transactional Outbox с RabbitMQ для гарантированной обработки асинхронных событий без потери данных.
- **Современный стек:** Go (версия по модулю сервиса), Python 3.13+ (Groq, FastEmbed, pgvector); aiogram и Flutter относятся к целевым клиентам.
