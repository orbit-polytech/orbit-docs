# client-mobile (Мобильное приложение Flutter)

**Репозиторий:** [`orbit-polytech/client-mobile`](https://github.com/orbit-polytech/client-mobile)

---

## 1. Назначение
Кроссплатформенное мобильное приложение Orbit AI для iOS и Android. Предоставляет студентам интерактивное расписание, навигацию по корпусам Политеха с этажными схемами аудиторий, трекер дедлайнов лабораторных работ и чат с AI-ассистентом.

---

## 2. Технический стек
- **Фреймворк:** Flutter 3.24+ / Dart 3.5+
- **Архитектура:** Feature-First (Слои Presentation, Domain, Data в каждой фиче)
- **Управление состоянием:** `flutter_bloc` 8.x (BLoC + Cubit, `sealed classes` для состояний)
- **Сетевой клиент:** `dio` 5.x с интерцепторами логирования и автоматического обновления токенов (`QueuedInterceptor`)
- **Безопасное хранилище:** `flutter_secure_storage` (Android KeyStore / iOS Keychain) для хранения JWT-токенов
- **Навигация:** `go_router` с декларативными маршрутами и редиректом при истечении авторизации

---

## 3. Архитектурное правило подключения к бэкенду
Мобильное приложение общается **исключительно с `gateway-service` по протоколу REST/JSON**. Приложение не использует бинарный gRPC и не открывает прямых сокетов во внутреннюю сеть бэкенда.

---

## 4. Сборка и запуск

```bash
# Установка зависимостей
flutter pub get

# Анализ кода
flutter analyze

# Запуск тестов
flutter test

# Запуск на эмуляторе/устройстве в режиме отладки
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080/api/v1
```
