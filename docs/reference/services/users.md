# users-service (Профили пользователей)

**Репозиторий:** [`orbit-polytech/users-service`](https://github.com/orbit-polytech/users-service)

!!! info "Статус: начальный каркас и целевая архитектура"
    В `main` создан начальный каркас; функциональность профилей, сервер и интеграция ещё не готовы. Этот паспорт описывает проектируемый сервис, а не готовую реализацию. Текущее задание, предлагаемые решения и критерии приёмки — на странице [«Разработка users-service»](../../project/tasks/users-service.md). Параметры паспорта уточняются при согласовании контракта и интеграции.

---

## 1. Назначение
Хранит и управляет профилями студентов, старост и преподавателей Московского Политеха: ФИО, учебная группа (например, `261-334`), факультет/институт, аватар, контакты, системные роли (`student`, `group_leader`, `curator`, `admin`).

---

## 2. Технический стек
- **Язык:** Go 1.26.10 в текущем каркасе (Clean Architecture)
- **База данных:** PostgreSQL 16 (`orbit_users`), пул `pgxpool`
- **Миграции:** Goose CLI (`migrations/`)
- **Протокол:** gRPC (порт `50052`)
- **Контракт:** `orbit.users.v1.UserService`

---

## 3. Выделенные порты и база данных
- **gRPC порт:** `50052`
- **База данных:** `orbit_users` в PostgreSQL
- **Healthcheck:** `/grpc.health.v1.Health/Check`

---

## 4. Обязательные переменные окружения

```ini
APP_ENV=local
LOG_LEVEL=debug
GRPC_PORT=50052

DB_HOST=localhost
DB_PORT=5434
DB_USER=orbit
DB_PASSWORD=
DB_NAME=orbit_users
DB_SSLMODE=disable
```

Пример рассчитан на запуск процесса на хосте с PostgreSQL, опубликованным на `localhost:5434`. При запуске внутри сети Docker используйте имя контейнера PostgreSQL и его внутренний порт `5432`. Наличие этих значений в `.env.example` не создаёт базу или роли автоматически: их подготовка и права — отдельный шаг, согласованный с ответственным за инфраструктуру. Не коммитьте пароль.
