# bot-service (Telegram-бот Orbit AI)

**Репозиторий:** [`orbit-polytech/bot-service`](https://github.com/orbit-polytech/bot-service)

---

## 1. Назначение
Официальный Telegram-бот для студентов, старост и кураторов Московского Политеха. Обеспечивает быстрый мобильный доступ к расписанию пар, напоминаниям о лабораторных работах, навигации по аудиториям и диалогу с AI-консультантом без необходимости установки отдельного приложения.

---

## 2. Технический стек
- **Язык и рантайм:** Python 3.12+ (uv / pip)
- **Фреймворк:** `aiogram 3.x` (асинхронный роутинг, FSM, фильтры `F.text`)
- **HTTP-клиент:** `httpx.AsyncClient` с постоянным пулом соединений (Connection Pooling)
- **Связь с системой:** Обращается **строго к `gateway-service` по REST API** с авторизацией по системному сервисному JWT или токену привязанного пользователя.

---

## 3. Архитектурное правило интеграции
Бот **никогда не обращается к внутренним базам данных напрямую** и не слушает gRPC-порты. Все действия (запрос расписания, создание дедлайна, вопрос к RAG) выполняются через публичный REST API шлюза `http://gateway-service:8080/api/v1`.

---

## 4. Обязательные переменные окружения

```ini
APP_ENV=local
LOG_LEVEL=info

# Telegram Bot Token от @BotFather
TELEGRAM_BOT_TOKEN="1234567890:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"

# Адрес API Gateway
GATEWAY_API_URL="http://localhost:8080/api/v1"

# Системный API ключ бота
BOT_SERVICE_TOKEN="secret-bot-token"
```
