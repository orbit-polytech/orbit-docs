# Референсы оформления Orbit Mobile

Скриншоты предоставлены командой для обсуждения макетов. Описание и подписи: [Дизайн: направления и референсы](../design-directions-and-references.md).

В папке семь разных изображений. Повторный скрин AI-чата не дублируется.

- `01-light-orange.svg` — светлый интерфейс с оранжевым акцентом.
- `02-warm-timeline.svg` — расписание на серо-бежевом фоне.
- `03-colorful-planner.svg` — цветной планировщик.
- `04-ai-chat.svg` — светлый AI-чат.
- `05-dark-orange.svg` — тёмный интерфейс с оранжевым акцентом.
- `06-warm-light.svg` — тёплый светлый интерфейс.
- `07-gradient-background.svg` — фон с персиково-сиреневым переходом.

## Формат

SVG — текстовая оболочка со встроенной WebP-копией скриншота, без внешних ссылок и скриптов. Пропорции сохранены; разрешение и сжатие WebP оптимизированы для просмотра в документации. Это растровые референсы внутри SVG, а не векторная перерисовка и не редактируемые макеты. Формат выбран из-за ограничения подключения GitHub на отправку бинарных файлов. Исходные PNG находятся во вложениях обсуждения; их можно позднее добавить обычным Git без изменения замысла страницы.
