# Flutter: Мобильное приложение Orbit Mobile

Репозиторий [**`mobile`**](https://github.com/orbit-polytech/mobile) содержит исходный код кроссплатформенного клиентского приложения для студентов Московского Политеха, работающего на **Android** и **iOS**.

---

## 1. Архитектурный манифест и границы ответственности

Архитектура клиентского приложения строится на четком разделении зон ответственности:

* **Clean Architecture** определяет границы модулей и направление зависимостей (`Presentation -> Domain <- Data`). Бизнес-логика полностью изолирована от деталей UI и низкоуровневых библиотек.
* **BLoC (`flutter_bloc`)** управляет потоком событий и состояниями пользовательского интерфейса через строгие конечные автоматы (`sealed classes`).
* **Репозитории и локальное хранилище Hive** реализуют бескомпромиссную стратегию **Offline-First (Cache-First)** для мгновенного доступа к расписанию без задержек сети.
* **Трансформеры событий (`bloc_concurrency`)** гарантируют защиту от гонок состояний (race conditions) при быстром вводе поисковых запросов и смене учебных групп.

### 📌 Статусы функциональных блоков:
* `[Реализовано]` — Шлюз API расписания (`GET /api/v1/schedule/groups/{group}`), базовый сервис авторизации.
* `[Принятое решение]` — Архитектурный фундамент Clean Architecture + BLoC, единое хранилище Hive, адаптивный Floating Dock, палитра Cron Dark.
* `[Запланировано]` — Серверные групповые задачи старосты (`tasks-service`), интеграция распознавания речи для аудиоконспектов.

## 2. Схема взаимодействия слоёв

```text
┌─────────────────────────────────────────────────────────────┐
│                     PRESENTATION LAYER                      │
│   [ Views / Widgets ]  ◄─── (ScheduleReady State) ───┐     │
│           │                                          │      │
│           ▼ (Events)                                 │      │
│   [ BLoC (ScheduleBloc) ] ───────────────────────────┘      │
└──────────────────────────┬──────────────────────────────────┘
                           │ вызывает UseCases
┌──────────────────────────▼──────────────────────────────────┐
│                        DOMAIN LAYER                         │
│   [ UseCases (GetCachedSchedule, SyncSchedule) ]            │
│   [ Pure Entities (Lesson, ScheduleData, Room) ]            │
│   [ IScheduleRepository (Контракт) ]                        │
└──────────────────────────▲──────────────────────────────────┘
                           │ реализует контракт
┌──────────────────────────┴──────────────────────────────────┐
│                         DATA LAYER                          │
│   [ ScheduleRepositoryImpl ]                                │
│       ├── LocalDataSource  ───► [ Hive NoSQL (Диск) ]       │
│       └── RemoteDataSource ───► [ Dio HTTP ] ──► Gateway    │
└─────────────────────────────────────────────────────────────┘
```

1. **Presentation Layer:**
   * **Виджеты (Views):** Отвечают исключительно за отрисовку интерфейса. Не содержат логики запросов в сеть или обращения к БД.
   * **BLoC:** Принимает события (`ScheduleEvent`), вызывает нужные UseCases и транслирует в UI неисключающие состояния (`ScheduleReady`).
2. **Domain Layer:**
   * Чистое ядро приложения без внешних Flutter-зависимостей. Содержит модели сущностей, бизнес-правила и абстрактные интерфейсы репозиториев.
3. **Data Layer:**
   * Реализует интерфейсы репозиториев. Оркестрирует локальный источник данных (`Hive`) и удаленный сетевой клиент (`Dio`).

## 3. Модель доступа: Гостевой онбординг vs Авторизация

Orbit Mobile решает главную студенческую проблему 1–2 сентября: падение внешних серверов вуза под пиковой нагрузкой не должно блокировать доступ к расписанию.

```text
               ┌──────────────────────────────────────┐
               │         Первый запуск Orbit          │
               └──────────────────┬───────────────────┘
                                  │
                                  ▼
               ┌──────────────────────────────────────┐
               │    Быстрый выбор учебной группы      │
               │        (Поиск из кэша Gateway)       │
               └──────────────────┬───────────────────┘
                                  │
              ┌───────────────────┴───────────────────┐
              ▼                                       ▼
  [ Гостевой доступ (Без пароля) ]       [ Вход через ЛК Политеха ]
  ├── 📅 Просмотр расписания группы      ├── 🤖 Доступ к ИИ-ассистенту
  ├── ⚡ Мгновенный кэш в Hive           ├── 👑 Режим старосты (рассылка лаб)
  └── 👤 Личные локальные задачи         └── 🔄 Облачная синхронизация
```

* **Гостевой доступ (Zero-Auth):** Студент вбивает номер группы (например, `261-334`) и сразу попадает на экран расписания. Никаких экранов ввода логина и пароля на старте.
* **Защитный экран (AuthWall):** При попытке открыть защищенный раздел (ИИ-ассистент, облачные функции старосты) приложение показывает стильную карточку с приглашением авторизоваться через Личный кабинет Московского Политеха.

## 4. Структура каталогов (`mobile/lib/`)

Проект организован по гибридной структуре (Core + Feature-First):

```text
mobile/
├── lib/
│   ├── app/                         # Инициализация приложения и роутинг
│   │   ├── app.dart                 # MaterialApp.router с темой Cron Dark
│   │   ├── observer.dart            # AppBlocObserver для логирования
│   │   └── routes/                  # Конфигурация GoRouter (StatefulShellRoute)
│   ├── core/                        # Общие системные модули
│   │   ├── error/                   # Иерархия ошибок Failure и Exception
│   │   ├── network/                 # Настроенный Dio, AuthInterceptor (мьютекс 401)
│   │   ├── storage/                 # Инициализация Hive и SecureStorage
│   │   └── theme/                   # Дизайн-токены Cron Dark (#08090B), типографика
│   ├── features/                    # Фичи приложения (Feature-First)
│   │   ├── schedule/                # Модуль «Расписание» (Cache-First)
│   │   │   ├── data/                # DataSources (Hive, Dio), Models, RepositoryImpl
│   │   │   ├── domain/              # Entities (Lesson, ScheduleData), UseCases
│   │   │   └── presentation/        # ScheduleBloc, HeroCard, TimelinePicker
│   │   ├── tasks/                   # Модуль «Задачи и дедлайны»
│   │   │   ├── data/                # Локальное хранилище задач в Hive
│   │   │   └── presentation/        # TasksBloc, TaskItemTile
│   │   ├── ai_assistant/            # Модуль «ИИ-помощник» (Protected)
│   │   │   └── presentation/        # AiChatBloc, AuthWallModal
│   │   ├── notes/                   # Модуль «Заметки и аудиоконспекты»
│   │   └── profile/                 # Модуль «Профиль студента и группа»
│   └── ui/
│       └── shell/                   # Главный контейнер с адаптивным Floating Dock
│           ├── adaptive_dock.dart   # Парящий Dock (5 вкладок, учет клавиатуры)
│           └── shell_screen.dart    # Обертка StatefulNavigationShell
```
