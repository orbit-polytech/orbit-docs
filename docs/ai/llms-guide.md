# Карта базы знаний для LLM (`llms.txt`)

Файл [`/llms.txt`](https://orbit-polytech.github.io/orbit-docs/llms.txt) предоставляет компактный машиночитаемый индекс документации для ИИ-агентов.

## Что содержит индекс

- актуальный Quickstart;
- страницу текущего состояния;
- архитектурные правила;
- основные руководства Go, Gateway, AI, Flutter и инфраструктуры;
- security/reference-разделы;
- правила для ИИ-агентов.

## Правило интерпретации

ИИ-агент обязан отличать:

- текущую реализацию;
- feature-ветки;
- целевую архитектуру;
- учебные примеры.

Источник статуса — страница [«Текущее состояние»](../project/current-state.md), а доказательство поведения — актуальный код и тесты соответствующего репозитория. Документация будущей архитектуры не считается подтверждением реализованной возможности.
