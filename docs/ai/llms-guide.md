# Карта базы знаний для LLM (llms.txt)

Этот раздел описывает стандартизированный файл машиночитаемой индексации базы знаний [**`llms.txt`**](file:///F:/Visual%20Studio%20Code/HOME/Git_rep/orbit-polytech/orbit-docs/docs/llms.txt), созданный по спецификации [llmstxt.org](https://llmstxt.org/).

---

## 1. Зачем нужен llms.txt?

Файл `/llms.txt` размещается в корне документации и служит компактным оглавлением для языковых моделей (LLM). Он позволяет ИИ-агентам мгновенно понять структуру проекта, найти нужную страницу без парсинга тяжелого HTML и точно определить правила кодогенерации.

---

## 2. Использование ИИ-агентами

Если вы используете Cursor, Claude Code, Aider или локальные скрипты анализа:
* Прямой адрес файла: `https://orbit-polytech.github.io/orbit-docs/llms.txt`.
* В файле собраны прямые ссылки на сырой Markdown всех страниц, сгруппированные по технологическим доменам.
