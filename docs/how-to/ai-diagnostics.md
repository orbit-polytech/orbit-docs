# Диагностика AI и RAG

Начните с [инструкции запуска](ai-local-stack.md). Используйте профиль `all`, если проверяете путь через Gateway.

```bash
docker compose --profile all ps -a
docker compose --profile all logs --tail 100 postgres-init ai-migrate ai-service gateway-service
```

| Симптом | Проверить |
|---|---|
| AI отсутствует после `task up` | Команда выбирает `apps`; используйте `--profile all` |
| Ошибка pull AI | Read-доступ к пакету `ai-service`, GHCR login, существование тега и платформы |
| AI не запускается в production | `GROQ_API_KEY`, `DATABASE_URL`, логи; fake не является fallback production |
| Мигратор завершился с ошибкой | pgvector-образ, расширение vector, provisioner, права, DSN; не удалять volume |
| `healthy`, но генерация падает | Health не вызывает Groq; проверьте модель, ключ, квоту и сеть |
| `401` | Access JWT; GHCR PAT не подходит для API |
| `403` | Владение диалогом/сообщением, пользователь JWT |
| `400`/`409` на повторе | UUID, одинаковый payload, активность и финальное состояние попытки |
| `200`, затем `event: error` | Это ошибка генерации внутри уже открытого потока; смотрите код события |
| Ответ есть, цитат нет | RAG_ENABLED, содержимое БД, активные версии, модель эмбеддингов, порог и top-k; не считать ответ подтверждённым |
| Клиент видит ответ целиком в конце | `curl -N`, SSE-парсер, proxy buffering и таймауты |
| `cancelled=false` | Генерация могла завершиться; также реестр отмены локален одному процессу |
| Live-тесты не запускаются | `POSTGRES_TEST_DSN`, миграции именно тестовой БД, расширение vector |

## Минимальная приёмка

1. Запуск из чистого клона и запуск с существующим volume без потери данных.
2. Валидный JWT → `start`, текст, при наличии источников `citations`, затем `done`.
3. Другой пользователь не читает replay и не отменяет чужой ответ.
4. Успешный replay совпадает по тексту и цитатам, без нового вызова LLM.
5. Пустая база, нерелевантный вопрос, ошибка провайдера, таймаут и отключение клиента обрабатываются явно.
6. Обновление документа исключает устаревшие фрагменты из поиска.

Факт зелёного unit-теста не равен проверке реального Groq; fake-тест не расходует токены и проверяет другой уровень. При передаче логов удаляйте JWT, API-ключи, DSN с паролями и пользовательские данные. Не прикладывайте полный `.env` или Docker config.
