# Ограничения текущей реализации AI

Эта страница отделяет имеющийся код от продуктовых обещаний.

| Есть сейчас | Пока не следует обещать |
|---|---|
| Группировка сообщений по `conversation_id` и сохранение результатов | Полноценная память: предыдущие реплики не добавляются в prompt текущего usecase |
| RAG по загруженным активным документам | Ответы по всему сайту университета, автоматическое обновление регламентов |
| Поиск и отдельные цитаты при найденных фрагментах | Цитаты в каждом ответе, доказанная корректность всех утверждений |
| Предупреждение модели при отсутствии подтверждения | Жёсткий программный запрет генерации без источников |
| Продуктовая направленность ассистента | Гарантированный отказ на любом вопросе вне тематики: нужны политика и отдельные тесты |
| Протокол StudentContext в contracts | Автоматическое получение профиля, расписания и дедлайнов; текущий HTTP DTO context не принимает |
| JWT на Gateway и владение ресурсами в AI | Публичный прямой gRPC, которому безопасно доверять произвольный `x-user-id` |
| In-memory реестр активных генераций | Распределённая адресная отмена между репликами |
| Лимит конкурентных генераций и выходных токенов | Полноценные пользовательские квоты и гарантированный контроль бюджета |
| Проверка БД и warmup до SERVING | Healthcheck, подтверждающий доступность Groq, актуальность документов или качество RAG |

Demo-корпус не является проверенным нормативным справочником. Реальный ответ может быть неверным даже с найденной цитатой: оценивайте соответствие утверждений источнику, а не только наличие `citations`. Для нормативного ответа без подтверждения интерфейс не должен изображать установленный факт.

Следующие этапы: проверенный корпус и оценка RAG; согласованная политика отказов; история диалога; инструменты Schedule/Users; квоты и наблюдаемость; координация генераций между репликами. Это предложения развития, не текущая функциональность.

**Основание:** [usecase](https://github.com/orbit-polytech/ai-service/blob/main/src/orbit_ai/application/chat_stream_use_case.py), [инициализация](https://github.com/orbit-polytech/ai-service/blob/main/src/orbit_ai/__main__.py), [HTTP DTO](https://github.com/orbit-polytech/gateway-service/blob/main/internal/transport/http/v1/ai/dto.go).
