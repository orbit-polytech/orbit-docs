# Ограничения текущей реализации AI

Эта страница фиксирует честные границы того, что уже работает в `ai-service`, и того, что обещать пока нельзя.

| Что уже есть сейчас | Чего пока нет (не обещать пользователям) |
|---|---|
| Список, загрузка истории и удаление диалогов; ограниченная история для контекста и переформулировки запросов | Бесконечная память на длинных диалогах и безошибочное разрешение любых местоимений |
| Гибридный RAG (pgvector + FTS, опциональный reranker) по загруженному `manifest.json` из `knowledge-pipeline` | Автоматическое обновление регламентов в реальном времени и ответы по всем закрытым разделам ЛК |
| Отдельные цитаты источников при срабатывании RAG | Цитаты в каждом ответе и гарантия, что каждый факт проверен на 100% |
| Маршрутизация ролей моделей (`router`, `casual`, `knowledge_rag`...) и fallback между провайдерами до первого токена | Мгновенное переключение посреди уже начатого потока или единый биллинг/квоты на каждого студента |
| Оценка качества на наборе `eval_harness` / `run_eval`, оценки 👍/👎 от студентов и триаж в `ops-bot` | Автоматическое дообучение модели или мгновенная автоправка базы знаний после дизлайка |
| Базовый парсер кодов аудиторий по правилам (`АВ-2315`, корпуса) | Полная карта маршрутов, этажей и расписание в диалоге (`schedule-service` ещё не подключён как tool) |
| Проверка владения диалогами и опциональный `ORBIT_INTERNAL_SERVICE_SECRET` | Безопасный публичный доступ к gRPC без Gateway (порт `:50057` только для доверенной сети) |
| Отмена активной генерации в рамках процесса | Распределённая отмена между несколькими репликами `ai-service` (реестр отмены in-memory) |
| Метрики Prometheus (`:9093`), трекинг токенов, квоты Groq/OpenRouter, алерты и дашборды Grafana | Пользовательские суточные лимиты запросов в Gateway/AI |

Даже если модель вернула ссылку в `citations`, конкретные цифры, суммы стипендий и сроки приёма документов всегда стоит сверять по первоисточнику, особенно если документ в `knowledge-pipeline` давно не пересобирался.

Ближайшее развитие: расширение и ручная вычитка корпуса в `knowledge-pipeline` по кейсам из `#untriaged`/`#feedback`, интеграция инструментов расписания и навигации, пользовательские квоты.

**Основание:** [pipeline.py](https://github.com/orbit-polytech/ai-service/blob/main/src/orbit_ai/application/chat_stream/pipeline.py), [router_client.py](https://github.com/orbit-polytech/ai-service/blob/main/src/orbit_ai/infrastructure/llm/router_client.py), [eval_harness.py](https://github.com/orbit-polytech/ai-service/blob/main/src/orbit_ai/scripts/eval_harness.py).
